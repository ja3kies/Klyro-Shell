## Progression du cycle 2

- Vérifié sur la branche `feat/product-overhaul-latest`: le test ZWJ est une régression de FIND au niveau terminal-buffer, et l’échec CI précédent provenait du fixture de test, pas du chemin de recherche. Le fixture a été corrigé et le test comportemental passe dans `44455689124`.
- Vérifié le chemin de publication Preview et les métadonnées de mise à jour dans le workflow courant. Pas de modification supplémentaire du mécanisme déjà fonctionnel.
- Audité la page App Updates: test de cible tactile et garde d’actions dupliquées existants; aucun nouveau défaut démontré dans le code étudié. Interaction Android et consentement d’installation restent non vérifiés.
- Revu les actions Terminal ciblées: le collage est lié à l’ID d’onglet et refuse les sessions terminées/changées; les collages multiligne nécessitent une revue; « Go to line » attend que l’IME et le viewport se stabilisent. Les recherches lisent le buffer terminal mutable et restent sur le thread UI; les tests actuels vérifient la logique de coordonnées, d’Unicode et de scrollback volumineux mais ne mesurent pas la latence physique. Aucun nouveau défaut fonctionnel confirmé.
- Revu Sessions/Workspaces: la confirmation de fermeture garde un ID stable, `closeTab(id)` ignore une session déjà absente et ne ferme que l’ID ciblé; supprimer un workspace réaffecte ses PTY à General sans les terminer. Les tests couvrent l’édition Unicode et les chemins de fermeture de modales; l’interaction réelle sur Android reste non exécutée.
- Défaut Plugins confirmé: `activeCommands()` masquait l’échec de lecture du registre sous forme de liste vide. La Command Palette affiche maintenant un état d’erreur sans détail sensible; le chemin nominal des packs installés reste testé. Correctif `718b478`, test nominal additionnel `aa5065a`.
- Revu Settings/App Updates: le changement de canal relance le contrôle, l’installation requiert le consentement Android et le dépôt Preview est le canal réellement publié par la CI. Aucun autre défaut de code démontré; téléchargement, annulation réseau et écran d’installation restent non vérifiés sur appareil.
- Revu Diagnostics/Freeze Reports: opérations de stockage et export sur IO; ZIP créé via SAF, erreurs d’export signalent explicitement qu’un document de destination peut être incomplet, et suppression ne cible qu’un identifiant de rapport. Les tests de suppression existent mais n’ont pas été exécutés sur Android.
- Revu Command Palette/Find: la palette insère les modèles validés sans envoyer Enter, les commandes marquées caution ouvrent une confirmation d’insertion, et le refus de PTY/input plein reste affiché. FIND conserve des coordonnées terminal et attend la fin du resize/IME avant le saut. Les protections et cas Unicode sont couverts côté JVM; aucun rendu/tap physique vérifié.
- Les autres écrans du cycle restent à traiter dans l’ordre; aucun statut « Validé » ne leur est attribué sur la seule base de compilation.

### Palette de commandes — recherche Unicode et aide

Quatre régressions reproduites puis corrigées dans KlyroCommandSearch et KlyroCommandCatalog : limite de recherche comptée en unités UTF-16, espace insécable ignorée comme séparateur, noms accentués canoniquement équivalents introuvables et recherche impossible par le véritable nom de la commande de stockage. Les quatre nouveaux tests échouaient avant correction. Après correction, les sept tests JVM ciblés et les 655 tests Python passent. Le texte de la commande exit décrit désormais la conservation de la session terminée jusqu’à fermeture explicite. Cette indication a été vérifiée dans le code de gestion des sessions. Interaction sur Pixel non exécutée.

Palette, suite du lot. La saisie et le défilement déclenchaient des accès disque synchrones pour vérifier les commandes. Un seul inventaire sur Dispatchers.IO alimente désormais les résultats et le filtre pendant l’ouverture. Le filtre indiquait exclure les utilitaires installés alors qu’il les proposait. Le compteur affichait « 1 commands ». Pour les commandes sensibles, le lecteur d’écran annonçait une insertion alors que le premier geste ouvrait une confirmation. Les trois indications ont été corrigées. Les 655 contrôles Python passent ; écoute TalkBack et latence sur appareil à vérifier.

Palette, refus d’insertion. Le chemin des commandes du catalogue masquait le clavier avant de connaître la réponse du terminal. Le clavier est désormais masqué après acceptation. Une rotation faisait également disparaître le motif du refus alors que la recherche et la palette étaient restaurées. La notice et son niveau de gravité suivent maintenant la même restauration. Un test Compose reproduit un refus puis restaure l’état et vérifie que le message reste affiché et que la commande a été proposée une seule fois. Test instrumenté ajouté, exécution sur appareil en attente. Les 655 contrôles Python passent.

FIND : chaque révision PTY annulait le délai de 170 ms avant lecture. Des révisions espacées de moins de 170 ms pouvaient repousser indéfiniment la première recherche. La révision est désormais observée par un collecteur qui conserve la dernière valeur pendant le délai ; changer la requête annule toujours le travail précédent. Autre défaut : l’aperçu marquait le contexte omis avant le résultat mais présentait le contexte tronqué après celui-ci comme une fin de ligne. La présentation indique maintenant les deux coupures, en préservant le texte brut copié. 20 tests JVM de recherche réussis, dont previewMarksOnlyAnOmittedSuffix. Cadence et rendu sur Pixel à vérifier.

FIND, navigation entre pages. Précédent et Suivant bouclaient sur les 300 correspondances de la page affichée. Depuis une page ancienne, Latest mettait à jour la sélection sans effectuer le défilement effectué par ce même bouton sur la page récente. Le saut est désormais effectué au chargement de la page. Test JVM : 701 occurrences sur une ligne, parcours intégral dans les deux directions, vérification de chaque position et du retour au départ. 21 tests FIND et 655 contrôles Python passent. Geste et défilement réel sur Pixel en attente.
